# 振り返りナビ

決めた行動を振り返り、次の行動につなげるフロー式の振り返りツールです。

**▶ アプリを開く：https://jun1994sp.github.io/furikaeri-navi/**

## できること

- **行動の登録**：KPIを達成するための行動を登録します。期間・頻度・振り返りの周期も一緒に決めます。
- **フロー式の振り返り**：1画面に1問ずつ答えていきます。
  - STEP 1：決めた頻度どおりに実行できたか、成果は出たかを答えます。
  - STEP 2〜4：答えに応じて、未実行／目標達成／目標未達成の3つのルートに分かれます。ルートごとに要因を選び、一番の要因を決め、改善策を考えます。
  - STEP 5：考え方・熱意・能力の3つの視点で、行動を「続ける／修正／入れ替え」から選びます。
  - STEP 6：次の振り返り日を決め、次回は STEP 1 に戻ります。
- **共有**：結果をテキストでコピーしたり、画像で保存したりできます。
- **リマインド**：振り返り日を、繰り返しの予定としてカレンダーに登録できます（Googleカレンダー／.ics）。
- **履歴と傾向**：行動ごとの経過、実行率、よく選ぶ要因のランキングを確認できます。
- **バックアップ**：データをJSONファイルに保存し、復元できます。

## データの扱い

記録は、使っている端末のブラウザ（localStorage）にだけ保存されます。外部のサーバーには送信されません。
機種を変更するときは、設定画面の「バックアップ」から移してください。

## 開発

ビルド工程のない静的サイトです（HTML／CSS／JavaScript）。

```bash
python3 -m http.server 8765
```

- `data.js`：要因一覧・ルート・3つの視点など、資料の文言
- `app.js`：画面と状態管理
- `style.css`：スタイル（ライトモードとダークモードに対応）
- `sw.js` / `manifest.webmanifest`：PWA対応（ホーム画面への追加、オフライン表示）
